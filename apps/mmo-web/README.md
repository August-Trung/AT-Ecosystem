# AT Tools - MMO Toolkit

Bo cong cu tien ich danh cho MMO/marketing/automation voi giao dien toi gian, khong tracking, tap trung vao hieu nang va trai nghiem.

## Tinh nang

- **Utilities**
  - Fake Identity, CC Generator, Global Time, User Agent Gen
  - Diff Checker, JSON/XML Formatter, List Extractor
  - Text Obfuscator, Fancy Text, Image Tools, Crypto Convert
  - Notepad, Temp Mail, File Share
- **Network**
  - WHOIS/IP lookup, Domain WHOIS
- **Dev Tools**
  - ID Generator (UUID/ULID/Nanoid), Timestamp converter
  - Regex Tester, Hash Utils (MD5/SHA)
  - JWT Tool, JSON Schema validator
  - SQL Formatter, HTTP Client + Curl builder
  - Cron Parser, Lorem/Fake data
  - API Response Viewer, JSON Diff
  - ENV Manager, UUID Validator, YAML ↔ JSON
- **SEO / Web**
  - Meta Preview, OG Checker
  - Sitemap/Robots generator, Redirect tester
  - Canonical & hreflang builder
- **Content**
  - Readability analyzer, Keyword extractor
  - Outline & headline templates
  - Markdown preview, Similarity checker
- **Industry Tools**
  - Design & Creative (resize, watermark, compress)
  - Marketing & SEO (UTM, meta preview, slugify)
  - Data & Office (CSV/TSV to JSON, dedupe)
  - Content & Writing (counts, readability, outline)
  - Photography (metadata strip, rename)
  - Finance (VAT/discount, loan calculator)
  - Education (flashcards generator)
  - HR & Recruitment (JD formatter, CV cleaner)
  - Legal & Docs (redaction, NDA template)
  - Sales (lead cleaner, scoring)
- **Security**
  - Password Generator, 2FA (TOTP) Generator
- **QR & Links**
  - QR Generator, QR Scanner, VietQR Generator
  - URL Shortener (is.gd, v.gd, TinyURL)

## Cong nghe

- React 19 + TypeScript
- Vite
- React Router
- Tailwind CSS (CDN)
- lucide-react icons

## Chay local

**Yeu cau:** Node.js (khuyen nghi LTS)

1. Cai dependencies:
   `npm install`
2. Chay dev server:
   `npm run dev`
3. Mo trinh duyet: `http://localhost:3000`

## Build & Preview

1. Build:
   `npm run build`
2. Preview:
   `npm run preview`

## Ghi chu

- Mot so tinh nang su dung API cong khai (1secmail, mail.tm, api.qrserver.com, allorigins.win, is.gd, v.gd, tinyurl). Tuy dieu kien mang va gioi han cua dich vu, ket qua co the cham hoac bi chan.
